# Installation

## Requirements

- Minecraft 1.21.1
- NeoForge
- Cybernetics
- Cybernetics: Vanity on the server and every client

## Official downloads

- [CurseForge](https://www.curseforge.com/minecraft/mc-mods/cybernetics-vanity)
- [Modrinth](https://modrinth.com/mod/cybernetics-vanity)

GitHub contains source code and documentation only. Do not download or redistribute unofficial JARs from GitHub mirrors or third-party websites.

Place the required JARs in the instance or server `mods` directory. Optional compatibility mods may be installed normally; no compatibility toggle is required.

Do not install multiple Cybernetics: Vanity versions at the same time. Server and client versions should match.

## Updating

Back up the world and configuration directory, replace the old JAR, and keep the same `cyberneticsvanity:vanity_implant` registry ID. Existing implants and saved vanity choices are designed to survive updates.
