# Using Cyber Vanity

1. Obtain a Vanity Implant. By default, villagers have a 12.5% base drop chance and Looting increases it.
2. Install the implant through Cybernetics surgery. It is a skin replacement and can replace Synthskin or Dermal Tissue.
3. Assign **Open Cyber Vanity Menu** in the Controls screen.
4. Open the menu and select individual implants, **Hide all**, **Show all**, or the master switch.

The menu contains a live rotating preview. Choices are persisted and synchronized so other players see the same appearance.

The Vanity Implant inherits Synthskin behavior, including uploaded tattoo information.
