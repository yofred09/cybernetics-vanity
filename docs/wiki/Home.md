# Cybernetics: Vanity Wiki

Cybernetics: Vanity is a client-and-server addon for Cybernetics that separates an implant's gameplay effects from its appearance.

## Important

The mod must be installed on both the server and every connecting client. Cybernetics is required. CPM, Pehkui, Corpse, Cyber Spells, Cyberchems, and Create are optional integrations.
