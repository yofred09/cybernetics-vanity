# Cybernetics: Vanity Wiki

Cybernetics: Vanity is a client-and-server addon for Cybernetics that separates an implant's gameplay effects from its appearance.

## Important

The mod must be installed on both the server and every connecting client. Cybernetics is required. Cyber Spells, Cyberchems, Create, and CPM Visual Bridge are optional integrations.

CPM models, Pehkui scaling, Sandevistan mirages, Holoprojector projections, and other external player renderers are handled by the separate [CPM Visual Bridge](https://github.com/yofred09/cpm-visual-bridge) project. Its public release is still in development.
