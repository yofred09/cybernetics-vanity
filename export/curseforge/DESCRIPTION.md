# Cybernetics: Vanity

Choose how your chrome looks without uninstalling it or losing its effects.

Cybernetics: Vanity is a cosmetic and compatibility addon for **[Cybernetics](https://www.curseforge.com/minecraft/mc-mods/cybernetics)** on [NeoForge](https://neoforged.net/) 1.21.1. Install the Vanity Implant and open a synchronized Robosurgeon-inspired menu to hide or show each installed cyberware visual independently.

## Official downloads

- [Download on CurseForge](https://www.curseforge.com/minecraft/mc-mods/cybernetics-vanity)
- [Download on Modrinth](https://modrinth.com/mod/cybernetics-vanity)

These are the only official download platforms. GitHub contains source code and documentation, but no compiled downloads.

## Main features

- Per-implant visual toggles
- Master switch, Hide all, and Show all
- Live rotating player preview
- First- and third-person support
- Persistent multiplayer synchronization
- Synthskin-based Vanity Implant with tattoo support
- Configurable acquisition, permissions, and implant requirement
- Optional missing-limb and Corpse appearance rules

## Compatibility

- **[Customizable Player Models (CPM)](https://www.curseforge.com/minecraft/mc-mods/custom-player-models):** prevents duplicate model passes and flickering; supports CPM Sandevistan mirages
- **[Pehkui](https://www.curseforge.com/minecraft/mc-mods/pehkui):** preserves scale in Sandevistan and Holoprojector projections
- **[Cyber Spells](https://www.curseforge.com/minecraft/mc-mods/cyber-spells):** compatible rune overlay visibility
- **[Corpse](https://www.curseforge.com/minecraft/mc-mods/corpse):** optional preserved corpse appearance
- **[Create](https://www.curseforge.com/minecraft/mc-mods/create), [Cyberchems](https://www.curseforge.com/minecraft/mc-mods/cybernetics-cyberchems), CPM, Pehkui, Cyber Spells, and Corpse are optional**

CPM Sandevistan rendering adapts the number of full model copies for better performance and can be disabled completely in the client settings. Pehkui scale remains active when it is disabled.

## Requirements

- Minecraft 1.21.1
- NeoForge
- [Cybernetics](https://www.curseforge.com/minecraft/mc-mods/cybernetics)

The addon must be installed on the server and connecting clients.

## Getting started

1. Obtain a Vanity Implant from a villager drop, or let the server disable the implant requirement.
2. Install it through Cybernetics surgery as a skin replacement.
3. Assign **Open Cyber Vanity Menu** in Controls.
4. Choose the visuals you want to keep.

Full setup, configuration, compatibility, and troubleshooting information is available on the **[GitHub wiki](https://github.com/yofred09/cybernetics-vanity/wiki)**. Problems can be reported through **[GitHub Issues](https://github.com/yofred09/cybernetics-vanity/issues)**.
